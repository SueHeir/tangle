# tangle.ct examples

Fitted from the raw scan with a grey profile per fiber type, measured around the true fibers. Each example's folder holds raw.tif, input.tif, true.tif, segment.tif, diff.tif, confidence.tif, fit.json and score.json. diff.tif: red = missed, blue = extra, orange = wrong fiber. confidence.tif: green = sure, red = unsure. Confidence AUC: how well low confidence picks out the wrong voxels (extra or wrong fiber) among fitted voxels, and the merged or false fits among all fits; 0.5 is chance, 1 is perfect.
